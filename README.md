Soy **Issac Brizuela**, desarrollador Full Stack proactivo y estratégico. No espero a que surjan los problemas: los anticipo y los resuelvo con soluciones que ahorran costos y abren nuevas oportunidades de negocio.

- 🛠️ **Full Stack Developer** en **ROSVEL** (2021 – 2023): modernización de sistemas críticos, migración de apps móviles legacy y arquitecturas multi-tenant.
- 🧩 **Freelance** (2025): sistemas administrativos a medida (reservas con cálculos dinámicos, inventario y pagos).
- 🤖 Me gusta meter IA donde realmente aporta: LLMs locales (LM Studio), OpenAI y Claude para extraer datos, fusionar conflictos y generar documentación.

## 🏆 Proyectos destacados

> Son repositorios privados

### 🛋️ CRM Tapicería · *Full Stack (API + Web + Móvil)*
CRM completo para un taller de tapicería: clientes y prospectos, proyectos con piezas e inspecciones, cotizaciones, pagos y facturación con catálogos SAT (CFDI 4.0), producción con evidencias y citas, inventario de telas y compras.
- **API:** Fastify 5 + Zod + Prisma con **doble motor de base de datos** (MySQL / SQLite) a partir de un único modelo, borrado lógico, bloqueo optimista por versión, importador de Excel y despliegue serverless en AWS Lambda + S3.
- **Colección Bruno autogenerada** desde las rutas reales, con la documentación redactada por un LLM local.
- **Web:** React 19 + Mantine + Vite, drag & drop con dnd-kit, E2E con Playwright, desplegada en AWS Amplify. App móvil en Flutter en camino.

`TypeScript` `Fastify` `Prisma` `MySQL` `React` `Mantine` `AWS` `Flutter`

### 💰 P-Salari · *Gestor de finanzas personales*
SPA que funciona sin servidor: cuentas, transacciones, presupuestos en 11 frecuencias, recordatorios automáticos y reportes (balance, ganancia neta, flujo de fondos).
- Backend **hexagonal dentro del navegador** (dominio → casos de uso → infraestructura) sobre AceBase / IndexedDB.
- **Lee en Gmail los avisos de tus bancos** y una IA local (LM Studio) detecta los movimientos para registrarlos; abre estados de cuenta PDF con contraseña (pdf.js).
- Formularios y modales generados desde JSON; pruebas con Vitest, Playwright y axe-core.

`Vue 3` `TypeScript` `Pinia` `IndexedDB` `Chart.js` `LM Studio` `Playwright`

### 🔄 Sincronizador de Documentación · *App de escritorio + extensión de VS Code*
App en segundo plano que mantiene sincronizada en ambos sentidos la carpeta `docs/` de cada repo con una bóveda central de Obsidian.
- Vigilancia de archivos en tiempo real, estado en SQLite, papelera de recuperación y widget de mascota en el escritorio con icono en la bandeja.
- **Resolución de conflictos con IA** (OpenAI o Claude) que fusiona las líneas en choque.
- Extensión de VS Code en TypeScript conectada a la app por WebSocket para mostrar el estado y sincronizar al guardar.

`Python` `PySide6` `watchfiles` `WebSockets` `OpenAI` `Claude` `VS Code API`

### ⚙️ EasyWebMaker · *Generador de backends*
Herramienta para acelerar la creación de APIs: escanea repositorios y, a partir de estructuras JSON, genera modelos (Sequelize / Bookshelf), controladores CRUD con relaciones y validaciones, scripts SQL y endpoints en formato Bruno.
- **Back:** Express + Sequelize + SQLite / MySQL, JWT + bcrypt, usuarios y roles, Jest + Supertest, semantic-release y commits convencionales.
- **Front:** Vue 3 + Pinia con editor visual de diagramas (Vue Flow), gráficas y tema claro / oscuro.

`Node.js` `Express` `Sequelize` `Vue 3` `Vue Flow` `Jest`

### 🔐 Email Manager · *Bóveda cifrada de cuentas*
App de escritorio (Windows / Linux) para organizar cuentas de correo, las apps y dominios ligados a cada una y su historial de contraseñas.
- Cifrado **AES-256-GCM** con derivación PBKDF2 calibrada por equipo; la llave de sesión solo vive en memoria.
- Escritura atómica con respaldo automático y bloqueo de la bóveda al minimizar la app.
- Diseño de la interfaz prototipado en Figma y llevado a React + MUI + Tailwind.

`Flutter` `Dart` `Criptografía` `Provider` `Figma`

### 🌐 Endpoint Gestor · *Cliente de APIs de escritorio*
Alternativa ligera a Postman / Bruno, offline-first: colecciones, peticiones, entornos y visor de respuestas; los workspaces se guardan como JSON en una carpeta elegida por el usuario.
- Tauri v2 + Nuxt 4 + Pinia, pruebas E2E con Playwright, auditoría de accesibilidad (axe-core) y regresión visual con pixelmatch.

`Tauri` `Nuxt` `Rust` `Playwright`

### ✨ Más proyectos

- **AppConta:** app contable con Quasar + Express 5 + Drizzle ORM (en desarrollo).
- **React Learning Lab:** laboratorio de React 19 de 0 a experto: Redux Toolkit, React Query, rutas protegidas, chat por WebSocket, Storybook y CI con GitHub Actions.
